AMOS Team : Корректировка регистрационных номер ВС

Created by Филипенков Никита Константинович, last modified on авг. 24, 2023
  1. Направить список регистрационных номеров ВС коллегам из ИНТЕГРО в группу Skype, для проверки наличие бортов в справочниках ММ.
  2. Заблаговременно проверяем с помощью SQL запросов в БД AMOS PROD следующие данные:

    1. Проверить данные о будущих рейсы

      SELECT *
FROM ac_future_flights
WHERE ac_registr IN ('73159', '73127', '73768', '73715')

    2. Проверить данные о задержках рейсов

      SELECT * 
FROM delay_cnl_import
WHERE ac_registr IN ('73159', '73127', '73768', '73715')

    3. Проверить данные об Event-ах

      SELECT *
FROM moc_daily_conseq
WHERE ac_registr IN ('73159', '73127', '73768', '73715')
      SELECT *
FROM moc_daily_records
WHERE ac_registr IN ('73159', '73127', '73768', '73715')

    4. Проверить данные о TQ

      SELECT * 
FROM tech_query 
WHERE ref_key in ('73159', '73127', '73768', '73715')

  3. Отправить 3 уведомления в APN 5 Messanger. В 21:00 (за 20 минут до начала работ выставить уведомление, за 10 мин и за 2 мин до начала работ) в AMOS PROD (параметры на скриншоте, текст сообщения в примечании):
     

    Текст уведомлений

    Уважаемые Коллеги!


    Через 20 минут (21:20 МСК 01.04.2022) на сервере AMOS PROD запланировано проведение работ по смене бортовых номеров:
     
    VQ-BMX --> 73159
    VQ-BWE --> 73127
    VP-BFG --> 73768
    VP-BEW --> 73715
     
    Продолжительность: 30 минут (AMOS PROD будет недоступен)

    Пожалуйста сохраните все изменения.

     _____________________________________________________________________
    Dear Colleagues!


    In 20 minutes (18:20 UTC 01.04.2022) on the AMOS PROD server scheduled technical work - change of the AC registration numbers:  

     

    VQ-BMX --> 73159
    VQ-BWE --> 73127
    VP-BFG --> 73768
    VP-BEW --> 73715
     
    Duration: up to 30 minutes (AMOS PROD will be unavailable) Please save all your work.  

     

    Best Wishes,

  4. В 21:10 отключить интерфейсы в APN 1404:
    1. TRANSFER FUTURE FLIGHTS
    2. TRANSFER EXECUTED FLIGHTS
    3. TRANSFER DELAYS AND CANCELLATIONS
  5. Повторно проверить отсутствие записей в БД с помощью SQL запроса описанному в пункте 2.

    1. В случае выявления записей в таблицах по «новым» регистрационным ВС на которые будет производиться замена .
      Удалить по уникальному ключу AC_REG все записи до начала работ (предварительно сохранив из таблицы в БД).

  6. В 21:20 отключить пользователей от ИС AMOS PROD в APN 10 (скриншот последовательности ниже).
  7. Коллеги из ДБА создадут точку восстановления, когда в APN 7 разорвутся все сессии у пользователей.

  8. После создания точки восстановления. Открыть APN 254 и заменить заменяющееся значение по умолчанию «Vendor Code» на «Aircraft Registration».

    Важно: checkbox «do not update tables containing *hist* не должен стоять (не будут заменены исторические значения).


  9. Заменить значения запланированных БН.
  10. По завершению корректировки проверить наличие новых БН в APN 308.
  11. Запустить интерфейсы (отключенные в пункте 4).
  12. Просить удалить точку восстановления коллег из ДБА.
  13. Запускаем пользователей:
    1. Удалить «0» из поля лимит сессий
    2. Убрать checkbox «Limit max. Amount of online users to»
    3. Нажать кнопку Save
    4. Проверить активные сессии в APN 7 (online Users)
  14. Проверить корректность отработки очередей и возможное кол-во зависших сообщений FF, EF, Delays (APN2606, APN992).
  15. Направить ответ по email о завершении работ.
