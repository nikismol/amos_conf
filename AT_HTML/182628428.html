AMOS Team : Отчет "Реестр компонентов"

Created by Филипенков Никита Константинович, last modified on июн. 11, 2025

Реализованы следующие представления(view) для данного отчета:

  1. AMOS_FSIGHT_BI_USER.R357_COMPONENT_REGISTRY_MATERIALIZED
  2. AMOSSERVER_PROD.R357_PART_REPAIR_VENDOR
  3. AMOSSERVER_PROD.R357_PARTNO_AC_TYPES
  4. AMOSSERVER_PROD.R357_PART_ALTERNATE


Для обновления материальной вью (R357_COMPONENT_REGISTRY_MATERIALIZED) настроен Oracle JOB:

  • MV_REFRESH_R357_COMPONENT_REGISTRY

Данный JOB запускается в 4 часа утра и обновляет данные в AMOS_FSIGHT_BI_USER.R357_COMPONENT_REGISTRY_MATERIALIZED.




SQL запросы находятся на GitLab. 

AMOS_FSIGHT_BI_USER.R357_COMPONENT_REGISTRY_MATERIALIZED

Данное представление выводит следующую информацию по материалам имеющие признак "REPLST":

  1. CRIT - уровень критичности
  2. CRIT_DESCRIPTION -  описание уровня критичности
  3. PARTNO - партийный номер 
  4. PARTNO_DESCRIPTION - описание 
  5. ALT_PARTNO - альтернативные партийные номера
  6. C_RATING - С-рейтинг 
  7. C_RATING_DESCRIPTION - описание С-рейтинга
  8. MAT_CLASS - материальный класс
  9. REPAIRABLE - ремонтопригодность
  10. AC_TYPE -  тип ВС к которым применим партийный номер 
  11. ATA_CHAPTER -  глава АТА
  12. OPERATOR
  13. CMM -  наименование CMM
  14. CMM_LINK - путь до СММ
  15. REPAIR_BASE_IN_RF - перечень организаций, уполномоченные на проведение ремонта по сертификатам Федерального агентства воздушного транспорта (ФАВТ)
  16. REPAIR_BASE_OUT_OFF_RF - остальные организации
  17. PLANNED_REQUIREMENT - плановая потребность на год вперед
  18. UNSCHEDULED_REMOVAL -  кол-во не запланированных снятий
  19. STOCK_BASE - кол-во исправных материалов(PARTNO)
  20. STOCK_ALT - кол-во исправных альтернативных материалов(ALT_PARTNO)
  21. STOCK_US -  кол-во неисправных деталей (PARTNO), исключая находящиеся во внутреннем ремонте
  22. REFRESH_DATE -  дата обновления view.
