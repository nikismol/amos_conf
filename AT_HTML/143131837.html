Настройка селектора в APN 1404

  • В Configuration Detail выбираем подвкладку selector и в окне Export Selector заполнить данные:

  • Ниже представлен SQL запрос для указания в Selector Options:

    select 
    shd.shipmentno_i
from sh_detail shd
left join /* Transfer history */(
    select aim.source_key_i
    from aim_transfer_history aim
    where aim.success = 'Y'
      and aim.service = 'TRANSFER_SHIPMENT'
      and ( aim.aim_configno_i = '8' or aim.aim_configno_i = '410')
      and aim.source_key_i is not null
    group by aim.source_key_i
    ) aim on to_char(shd.shipmentno_i) = aim.source_key_i
where aim.source_key_i is null /*  and shd.status = 0  */
  and shd.state <> 'M' and shd.state <> 'O' 
  and shd.shipmentno_i > 20000 
  and shd.shipmentno_i != 102576 
group by shd.shipmentno_i

Настройка селектора в APN 1404

  • В Configuration Detail выбираем подвкладку selector и в окне Export Selector заполнить данные:

  • Ниже представлен SQL запрос для указания в Selector Options:

    select 
    shd.shipmentno_i
from sh_detail shd
    left join /* Transfer history */(
    select aim.source_key_i
    from aim_transfer_history aim
    where aim.success = 'Y'
      and aim.service = 'TRANSFER_SHIPMENT'
      and aim.source_key_i is not null
      and  aim.aim_configno_i = '811'
    group by aim.source_key_i) aim on to_char(shd.shipmentno_i) = aim.source_key_i
where aim.source_key_i is null  /*  and shd.status = 0  */
  and shd.state <> 'M' and shd.state <> 'O' 
  and to_date('31.12.1971', 'dd.mm.yyyy') + shd.mutation > to_date('01.09.2020', 'dd.mm.yyyy')
group by shd.shipmentno_i
