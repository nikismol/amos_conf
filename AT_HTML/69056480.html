AMOS Team : Определение сервера Citrix

Created by Филипенков Никита Константинович, last modified on сент. 29, 2023

Для определения сервера Citrix необходимо: 

  1. Выполнить вход в Citrix и выполнить запуск ИС AMOS. 
  2. Открыть "Центр подключений" с помощью панели задачи Windows.
  3. В подключениях будет отображать необходимый сервер.
