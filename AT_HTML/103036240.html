AMOS Team : Запрос для получения сертификата с Web Drive.

Created by Филипенков Никита Константинович, last modified on сент. 29, 2023 
SELECT
    certificate.form_tracking_no,
    '\\msk.aeroflot.ru\amos\PROD\WEB_DRIVE\'||ste_content_list.engine_id,
    certificate_link.source_key as rotable_psn
FROM
    certificate_link
LEFT JOIN
    certificate ON certificate.certificate_i = certificate_link.certificate_i
LEFT JOIN
    db_link ON db_link.source_type = 'CERT' AND db_link.source_pk = certificate.certificate_i
LEFT JOIN
    ste_content_list ON ste_content_list.storage_id = db_link.destination_key
WHERE
    certificate_link.source_type = 'RO'
    AND certificate_link.source_key IN ( SELECT DISTINCT psn FROM history WHERE partno = '@VAR@' AND serialno = '@VAR@')


Подставить необходимый Partno и Serialno

Результатом является путь к файлу сертификата на WD (можно попасть по этому пути через сервера AMOS – если нет доступа, можно попросить Сергея Королева или Влада Рыбина).
