AMOS Team : Передача OPUS FREE TEXT в СКООг

Created by Белых Александр Петрович, last modified by Филипенков Никита Константинович on сент. 29, 2023

Передача данных введенных ИОО вручную в поле Free Text для OPUS в WO, схема должна быть относительно статична.

Аборин Дмитрий Александрович RE Поле free text в составе сообщения об отложенном дефекте.msg Mon 10:27 AM 415 Кбайт

DDL
CREATE VIEW AMOSSERVER_PROD.SKOOG_WO_FREE_TEXT
AS SELECT
woh.event_perfno_i as task_id
, wo_opus.free_text as opus_free_text
FROM
wo_header woh
LEFT JOIN wo_opus ON wo_opus.event_perfno_i = woh.event_perfno_i;

GRANT SELECT ON AMOSSERVER_PROD.SKOOG_WO_FREE_TEXT TO AMOS_IL_USER;

CREATE SYNONYM AMOS_IL_USER.SKOOG_WO_FREE_TEXT FOR AMOSSERVER_PROD.SKOOG_WO_FREE_TEXT;
TEST SQL
SELECT * 
FROM AMOS_IL_USER.SKOOG_WO_FREE_TEXT 
WHERE opus_free_text IS NOT NULL;
--MUST SHOW RESULTS, NO ERRORS. ERRORS OR EMPTY - VERIFY AMOS WO_OPUS SCHEMA CHANGES
