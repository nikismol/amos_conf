AMOS Team : Недоступность ИС AMOS через Citrix

Created by Филипенков Никита Константинович, last modified on сент. 29, 2023

При обращении пользователей на недоступность ИС AMOS через Citrix специалисту 1 линии поддержки необходимо:

  1. Самостоятельно осуществить вход в ИС AMOS через Citrix из под своей УЗ. 
  2. Проверить работоспособность (хотя бы частичную клиентского ПО AMOS PROD на каком то из Серверов). Далее для непрерывности рабочего процесса пользователей направляем пользователям обходное (временное) решение для входа в AMOS PROD (инструкция ниже).
      
  3. Для выявления нерабочего сервера Citrix с клиентским ПО AMOS необходимо посмотреть на каком сервере осуществляется запуск ИС AMOS а на каком нет (возможно методом исключения). ПКМ в по ярлыку Citrix в taskbar notification area → Центр подключений ( в момент запуска AMOS) 


    Список серверов :
    • SVO-XA-04-01
    • SVO-XA-04-02
    • MLK-XA-04-01
    • MLK-XA-04-02
    • MLK-XA-04-03
    • MLK-XA-04-04
    • MLK-XA-04-05

      3. Если запуск клиентского ПО AMOS не осуществляется на каком то из серверов Citrix, то:
      1. Оповестить Рыбина В.Н., Кокорина И.С., Королева С.Е. по установленным каналам связи (whatsapp, звонок по мобильному в зависимости от времени суток, skype)
      2. Написать соответствующее письмо
