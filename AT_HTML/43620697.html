AMOS Team : Долго открывается WO в APN 1

Created by Дамрин Степан Валерьевич, last modified by Филипенков Никита Константинович on сент. 11, 2019

Во время работы с APN 1 возникает длительная загрузка при выборе любого WO

Причина:

Проблема проявляется, так как во время выбора WO из списка, автоматически подгружаются данные в печатную форму в окне предпросмотра отчета(report).

Решение: 

  1. Для быстрой работы данной APN 1 рекомендуется выбрать вместо Report вкладку Summary.
  2. Посоветовать пользователю расширить память в клиенте AMOS ( AMOS → Configure → Set Client Memory выбрать 2048 Mb нажать кнопку "Ok")
  3. Рекомендовать пользователю выполнять выгрузку по меньшему количеству бортов.
  4. Рекомендовать пользователю использовать отчет "133_WO_information" (Applications → Reports → Planning → 133_WO_information или APN 10094)
