AMOS Team : Массовая корректировка ATA-Chapter для партийный номеров

Created by Филипенков Никита Константинович, last modified on авг. 24, 2023

Для корректировки ata_chapter осуществляется замена данных в следующих полях таблицы 'part' БД AMOS :

  • ata_chapter
  • mutator
  • mutation
  • mutation_time
UPDATE part SET ata_chapter='указывается глава АТА', mutator='указывается логин', mutation='AMOS дата', mutation_time='AMOS время' WHERE part.partno='партийный номер'
