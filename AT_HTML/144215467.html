AMOS Team : Массовая корректировка SPEC-КОДОВ для партийных номеров

Created by Филипенков Никита Константинович, last modified on авг. 15, 2023

Для корректировки Spec-кодов осуществляется замена данных в следующих полях таблицы 'part_specia' БД AMOS :

  • special
  • mutator
SQL для корректировки SPEC-кодов
UPDATE part_special SET special='новое значение', mutator ='указывается логин' WHERE partno='партийный номер' AND special='старое значение';
