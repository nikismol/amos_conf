AMOS Team : Создание профиля в Oracle DB

Created by Филипенков Никита Константинович, last modified on авг. 27, 2025

Создание профиля у которого пароль бессрочный пароль


CREATE 
    PROFILE PROFILE_FOR_USERS_UNLIMITED 
    /* PASSWORD_LIFE_TIME - данный параметр отвечает за срок действия пароля */
    LIMIT PASSWORD_LIFE_TIME UNLIMITED ;

Назначение профиля пользователю


Для нового пользователя


CREATE USER test_user IDENTIFIED BY user_password
  PROFILE PROFILE_FOR_USERS_UNLIMITED;

Для существующего пользователя


ALTER USER test_user PROFILE PROFILE_FOR_USERS_UNLIMITED;

Поиск созданного профиля с бессрочным паролем

SELECT
    profile,
    resource_name,
    limit
FROM dba_profiles
WHERE resource_name='PASSWORD_LIFE_TIME'
  AND limit='UNLIMITED'
