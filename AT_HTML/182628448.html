AMOS Team : Отчет "Детальный отчет по закрытым ремонтным заказам (R, PX)"

Created by Филипенков Никита Константинович, last modified on июн. 11, 2025

Реализованы следующие представления(view) для данного отчета:

  1. AMOS_FSIGHT_BI_USER.R348_CLOSED_ORDERS_TRACKING_MATERIALIZED


Для обновления материальной вью (R348_CLOSED_ORDERS_TRACKING_MATERIALIZED) настроен Oracle JOB:

  • MV_REFRESH_R348_CLOSED_ORDERS_TRACKING_MATERIALIZED

Данный JOB запускается в 4 часа утра и обновляет данные в R348_CLOSED_ORDERS_TRACKING_MATERIALIZED.

SQL запросы находятся на GitLab. 

AMOS_FSIGHT_BI_USER.R348_CLOSED_ORDERS_TRACKING_MATERIALIZED

  1. ORDERNO - номер заказа
  2. ORDER_DATE -  дата создания заказа
  3. PARTNO -  партийный номер
  4. SERIALNO - серийный номер
  5. MAT_CLASS - материальный класс
  6. PARTNO_DESCRIPTION - описание партийного номера
  7. QTY -  кол-во материалов в заказе
  8. ORDER_STATE - статус позиции заказа
  9. VENDOR_CODE - реальный код поставщика.
  10. VENDOR_CODE_FOR_TAT - код поставщика из заказа.
  11. VENDOR -  наименование поставщика
  12. REMOVAL_DATE -  дата снятие материала с ВС
  13. QTY_DAYS_IN_DTO_TO_SENT -  кол-во дней прошедших с даты демонтажа на склады ДТО до даты отправки на склад ДУЗД
  14. QTY_DAYS_IN_AFLT_TO_SENT -  кол-во дней прошедших с даты демонтажа на склады АФЛТ до даты отправки на склад ДУЗД
  15. QTY_DAYS_IN_TRANSIT_FROM_AFLT_TO_DUZD_TO_SENT -  кол-во дней в трансфере
  16. QTY_DAYS_IN_DUZD -  кол-во дней на складах ДУЗД
  17. QTY_DAYS_IN_SENT - кол-во дней с момента отправки до даты ресивинга
  18. QTY_DAYS_NOT_ON_AC - кол-во дней нахождения материала с даты демонтажа до даты ресивинга
  19. SENT_TO_REPAIR - дата отправки в ремонт по AMOS
  20. SENT_TO_REPAIR_FROM_BASE - признак отправки с базы/вне базы
  21. SENT_TO_REPAIR_FROM_BASE_DESCRIPTION - описание признака отправки с базы/вне базы
  22. INTERNAL_REPAIR_CODE - признак внутреннего ремонта
  23. INTERNAL_REPAIR_DESCRIPTION - описание признака внутреннего ремонта
  24. RECEIVING_GOODS_DATE - дата ресивинга по заказу
  25. TRASFER_DATE_AFTER_B1 - дата первого перемещения после ресивинга
  26. REC_TRASFER_DATE_AFTER_B1 - дата приема материала первого трансфера 
  27. REFRESH_DATE - дата обновления view.
