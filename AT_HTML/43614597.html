Настройка WIFI
WiFi

SSID:

  1. INTERNET1 пароль: aeroflot
  2. AFL_STAF2 логин и пароль: это логин и пароль от учётной записи аэрофлот

Примечание:

*1 Данная сеть является сетью общего пользования с доступом в интернет, поэтому для доступа к ресурсам компании Аэрофлот, в первую очередь к программному комплексу AMOS вам необходимо использовать VPN соединение (смотри настройки ниже)

*2 Данная сеть является внутренней сетью компании Аэрофлот, в ней вы можете напрямую пользоваться ресурсами компании, но при в ней отсутствует доступ к интернету. (рекомендуется использовать только при нерабочем состоянии WiFi сети INTERNET.

Настройка VPN


VPN

Для доступа к системе AMOS при использовании любой сети за исключением AFL_STAF необходимо использовать подключение через VPN туннель, для его настройки необходимо скачать и установить если у вас нет следующее приложение CiscoAnyConnect.

Установка и подключение CiscoAnyConnect

Руководство по установке и настройке

  • Скачайте CiscoAnyConnect:
    для Windows - anyconnect-win-4.3.02039-web-deploy-k9.exe
    для MAC OS - anyconnect-macos-4.10.05095-core-vpn-webdeploy-k9.dmg


  • Устанавливаем программное обеспечение
  • В появившемся окне вводим адрес сервера VPN (vpncorp.aeroflot.ru)
  • Жмём Connect

  • Заполняем учётные данные для входа в личный кабинет компании Аэрофлот
  • Жмём OK

ПОСЛЕ УСПЕШНОЙ АВТОРИЗАЦИИ ВЫ МОЖЕТЕ ПОДКЛЮЧАТЬСЯ К СИСТЕМЕ AMOS

Установка и полключение OpenConnect

Руководство по установке и настройке

  • Скачайте OpenConnect:
    для Windows -  openconnect-gui-1.5.2-win32.exe
    для MAC OS - openconnect-gui-bottle.tar


  • Устанавливаем программное обеспечение
  • В появившемся окне переходим по следующему пути:- File->Profiles→New profile

  • В появившемся окне:
    • Ставим галку в чекбоксе Customize и задаем имя подключению в поле "Name"
    • В поле Geteway вводим адрес сервера VPN (https://vpncorp.aeroflot.ru)
  • Жмём "Save & Connect"
  • При возникновении предупреждения нажмите "Accurate Information"
  • Заполняем учётные данные для входа в личный кабинет компании Аэрофлот
  • Жмём OK
  • После успешного входа индикатор должен загореться зеленым цветом
